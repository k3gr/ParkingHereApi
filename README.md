## Overview

**ParkingHereWebApi** is a comprehensive platform for managing parking spaces and reservations. The application serves two main user groups:

### 👥 For Individual Customers
- Search for available parking spots in specific locations
- Reserve parking spaces easily
- Access personal management panel
- Track reservations

### 🏢 For Business Customers
- Add parking lots to the database
- Manage multiple parking facilities
- Track and manage all reservations
- Monitor parking space availability

**Security**: JWT-based authentication  
**Hosting**: Microsoft Azure

---

## ✨ Features

- 🔐 Secure authentication with JSON Web Tokens (JWT)
- 🔍 Advanced parking search engine
- 📅 Real-time reservation system
- 👤 User management panel
- 🏢 Business dashboard

## Opis

**ParkingHereWebApi** to wszechstronna platforma do zarządzania miejscami postojowymi i rezerwacjami. Aplikacja służy dwóm głównym grupom użytkowników:

### 👥 Dla klientów indywidualnych
- Wyszukiwanie dostępnych miejsc postojowych w wybranych lokalizacjach
- Łatwa rezerwacja miejsc postojowych
- Dostęp do panelu zarządzania
- Śledzenie rezerwacji

### 🏢 Dla klientów biznesowych
- Dodawanie parkingów do bazy danych
- Zarządzanie wieloma obiektami
- Zarządzanie rezerwacjami i monitorowanie dostępności miejsc
- Pełna kontrola nad parkingami

**Bezpieczeństwo**: Autentykacja przy użyciu JWT  
**Hosting**: Microsoft Azure
